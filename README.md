## Sobre o Quiz
<table>
  <tr>
    <td width="100% valign="top">
      
O **Data On'Quiz** é uma aplicação web de um projeto prático para a nossa disciplina de Desenvolvimento Front-End Web. O foco principal foi estruturar o aprendizado em construção de interfaces, manipulação de dados dinâmicos e boas práticas de trabalho em equipe com Git e GitHub.
O quiz traz perguntas sobre a área de Dados e suas tecnologias, com feedback imediato para cada resposta, explicações detalhadas com links de fontes confiáveis, visualização de pontuação e ranking da sessão. Tudo isso para tornar a experiência mais imersiva e divertida, alem de auxiliar no aprendizado.

### Propósito

**Prática Técnica:**

Aplicação prática de conceitos fundamentais da área de dados, focando em modelagem, gerenciamento de bancos de dados e otimização de estruturas.

**Trabalho em Equipe:**

Simular um ambiente real de desenvolvimento, com divisão de tarefas por branchs, controle de versão e resolução de conflitos ao mesclar alterações.

**Ferramentas e Linguagens Utilizadas**

- **HTML5:** Estrutura semântica das páginas, incluindo a tela inicial e a tela de jogo.

- **CSS:** Estilização responsiva e acessível, com atenção à legibilidade, contraste e navegação por teclado.

- **JavaScript:** Lógica do jogo, manipulação do DOM, armazenamento local e requisição completa.

- **JSON:** Armazenamento e organização das perguntas e respostas do quiz.

- **Git & GitHub:** Controle de versão distribuído, fluxo de trabalho colaborativo com branches e hospedagem HTTPS.

- **VS Code:** Ambiente de desenvolvimento integrado usado para codar e testar a aplicação.

O **Data On'Quiz** foi pensado para ser funcional, acessível e com bom desempenho, além de servir como uma ferramenta para treinar os conhecimentos adquiridos no assunto.
